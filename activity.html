5. HTML DOM

The HTML DOM represents the webpage as a tree of elements. Each element can have a parent, children, and other related elements.

DOM Tree Example

  • HTML is the root element.
  • Body is a child of HTML.
    • Headings are children of Body.
    • Paragraphs are children of Body.
